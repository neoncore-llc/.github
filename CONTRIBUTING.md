# Contributing Guidelines

Thank you for contributing to **NeonCore LLC** repositories.

## Workflow & Pull Requests

1. **Branch Naming:** Use descriptive branch names (`feat/<scope>`, `fix/<scope>`, `chore/<scope>`, `docs/<scope>`).
2. **Conventional Commits:** Format commit messages using Conventional Commits (`feat:`, `fix:`, `chore:`, `ci:`, `docs:`).
3. **Pull Request Checklist:** Complete all sections in the Pull Request template and verify that automated CI checks pass before requesting review.
4. **Information Hygiene:** Never include credentials, internal endpoints, or sensitive operational details in public issues, pull requests, or commit messages.
